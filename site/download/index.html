What you need

System requirements

FlashDesk has been kept deliberately lean. There is no framework to install and no dependency to satisfy — just the file.

  • Windows 10 x64 or Windows 11 x64 32-bit Windows is not supported. Home, Pro, and Enterprise editions all work.
  • Internet connection (both computers) Used only during the session, to relay the screen and control input.
  • No .NET framework installation required The runtime is self-contained inside the file.
  • No account or registration Open the file and it generates a session number. No sign-up, no email address.
  • No router or firewall configuration Connections route through an intermediate relay server. Ports 80 and 443 work on most networks without changes.
  • Not supported: macOS, Linux, Android, iOS FlashDesk is a Windows desktop program. The helper side runs on any computer with a browser.

Did someone phone you and send you here?

Hang up. Legitimate helpers do not phone you first and then ask you to download software. Only use FlashDesk if you contacted the helper yourself — through a number you looked up, not a number they gave you.

Before you run it

Three steps from download to connected

  1. Download the installer using the button above. Right-click the downloaded file → Properties → tick Unblock → OK. The Security warning page shows you exactly what to expect.
  2. Run FlashDesk-setup.msi. An administrator password is required at install time. Once installed, open FlashDesk from the Start menu — it shows you a 9-digit number.
  3. Share your number with the person helping you — by phone or message is fine. When they connect, you will see a request appear on your screen. Click Accept to begin the session. You can disconnect any time by closing the window.
