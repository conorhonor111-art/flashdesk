Three steps

  1. Download the file and open it. Nothing installs.

Both of you run the same file. Whoever types a number is the one who sees the other person’s screen.

Windows will warn you when you open it. This is normal.

A blue box appears. It says:

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.
More info
Don’t run

There is no way forward on this screen. The only button is Don’t run. The button you need does not exist yet.

Click the small grey words More info. They are a link, not a button, and they are easy to miss. The box then grows and shows:

App:      FlashDesk.exe
Publisher: Unknown publisher
Run anyway Don’t run

Now press Run anyway, on the left.

If nobody you telephoned yourself asked you to do this, press Don’t run and close this page. Somebody who phoned you out of the blue and talked you as far as a security warning is not helping you.

“Unknown publisher” is the honest part. It does not mean the file is unsafe. It means nobody has paid a certificate authority to attach a verified name to it. If I had, that line would read Publisher: Conor Honor instead of Unknown publisher — the file would be exactly the same file.

Why it happens at all. Windows trusts software it has seen many people run before, and counts everything else as unrecognised. FlashDesk is new, so it is unrecognised. That is the entire reason, and it is also why the wording is as strong as it is: your computer genuinely cannot tell the difference between new software and bad software, so it warns about both.

What this does — and what it does not

  • It lets your helper see and control your screen — while you watch everything they do.
  • You can end the session at any moment with one click.
  • It does not run when you close it. Close the window and it is gone.
  • Nothing is installed unless you choose to install it.
