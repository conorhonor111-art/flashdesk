Download FlashDesk for Windows

Free · about 65 MB · Windows 10 and 11

If someone phoned you out of the blue and told you to come here, hang up. Only download this if you contacted us yourself.

Three steps

  1. Download the file and open it. Nothing installs.
  2. It shows you a 9-digit number.
  3. Read that number to the person helping you — or type theirs in and press Connect.

Both of you run the same file. Whoever types a number is the one who sees the other person’s screen.

Windows will show a blue warning

Windows shows a blue warning for new software it has not seen before. Click More info, then Run anyway. That is all.

What this does — and what it does not

  • It lets your helper see and control your screen — while you watch everything they do.
  • You can end the session at any moment with one click.
  • It does not run when you close it. Close the window and it is gone.
  • Nothing is installed unless you choose to install it.
