# FlashDesk

Remote support for Windows. One file, nothing installs.

The person being helped runs it, reads out a 9-digit number, and presses **Accept** before anything
is shared. While a session is running they can see it on their screen and end it with one click,
and every connection is written to a plain text file on their own machine.

**Download it from the release on the right, or from [flashdesk.org](https://flashdesk.org) — where
there are instructions in plain language, including the two warnings Windows shows for new
software.**

---

### Why the source is not here

FlashDesk is not open source. This repository exists to host the download, because a browser is far
less suspicious of a file from GitHub than of the same file on a small website — and the people this
is built for are the least equipped to argue with a browser warning.

If you were hoping to read the code before running it, that is a reasonable thing to want, and I
would rather say so plainly than have you find an empty repository and wonder.

### What it does, and what it does not

- It lets someone see and control your screen — **while you watch everything they do**.
- **You accept every session by hand.** Nobody can connect without you pressing Accept.
- **You can end it at any moment**, with one click.
- **It does not run when you close it.** Close the window and it is gone.
- Nothing is installed unless you choose to install it.
- Every connection is logged on your own computer, in a file you can open.

### If someone told you to download this

If a person phoned you out of the blue and told you to come here, **hang up**. Only download this if
you contacted us yourself. That warning is the same one on the website, and it is there because this
kind of software is exactly what telephone scammers ask people to install.
