How it works

Every claim here is checked against the code.

Not something the program is meant to do — something it actually does. If a claim could not be verified against the source, it is not on this page.

The file panel can copy a file. It cannot delete, rename or move anything.

What a session can do

Eight things, each one checkable.

Nothing installs

It is one file. There is no installer step, and no administrator password is asked for to run it — the program starts with the same permissions as any other window you open. (A separate, optional "install it properly" mode has been talked about but does not exist yet — today, everyone runs the same portable file.)

The number is an address, not a password

Your 9-digit FlashDesk number is generated on your machine and identifies it to the relay that connects two computers together — it is how a helper finds you, the way a phone number finds a house. A separate, private value your computer never displays is what actually proves ownership of that number, and the relay checks it on every connection.

Every new session is accepted by hand

An incoming connection shows a dialog with the caller's number and two buttons, Accept and Reject. While that dialog is open, FlashDesk's own remote-control input is blocked from reaching it — the program asking for control cannot also be the thing that presses Accept. If a connection drops and the same caller reconnects within 90 seconds, that resumes without asking again; a different caller is always asked.

A strip stays on screen, and cannot be hidden

While anyone is connected, a coloured band stays on your screen for the whole session. It belongs entirely to the window running on your own computer — there is nothing the connected helper can send that touches it. It disappears when the session ends, not before.

A log stays on your computer

Every connection — who asked, when, whether you accepted or refused — is written to a plain text file on your own machine. It stays there unless you separately let your helper copy files off your computer — the same permission that protects everything else there. It does not record your screen, anything you typed, or the contents of any file.

File access is a second, separate question

Accepting a session lets a helper see your screen; it does not by itself let them open your files. Looking at your files needs its own, separate permission, asked for the first time it is needed.

Copy, never delete or rename

Once file access is granted, a helper can look through your files and copy one to their own computer, or send you one of theirs. There is no delete, rename or move — those simply do not exist as things the file panel can ask your computer to do, by design.

An arriving program is named every time

If a helper sends you a program rather than an ordinary file, you are asked about it by name — the file's name and where it would be saved — every single time, even after you have already agreed to file access generally.

What it does not do
  • No background service. FlashDesk only runs while its window is open.
  • No autostart. It does not add itself to Windows' startup list or run when you log in.
  • Closing the window ends everything — the session, the capture, the connection. There is nothing left running afterward.
  • If your computer has more than one screen, your helper currently sees and controls only the one you're on. Switching between screens for them is planned but not built yet.
