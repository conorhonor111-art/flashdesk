Frequently asked questions

Not the questions a product page usually answers — the ones a person actually has, sitting in front of the download.

The first time anyone connects, a human has to press Accept. There is no way around it, and no way to do it for them.

Is this safe?

The download itself is unsigned software from a small, one-person project, so Windows and your browser both warn you about it — that part is normal and explained on the home page. Once it is running, the session itself has real limits built in: nobody can connect without you pressing Accept the first time, a coloured strip stays on your screen for as long as anyone is connected and cannot be hidden by the other side, and you can end it with one click at any moment. Read how a session actually works for the full list of what is and is not possible.

The one thing no software can protect you from is being talked into pressing Accept for someone who should not have it. That is what the warning on the home page and the line at the bottom of every page are for.

Why does Windows warn me when I open it?

Windows Defender SmartScreen warns about software it has not seen many people run before, and it has not been paid to attach a verified publisher name to the file (that costs money every year and buys reputation over time, not on day one — it has not been bought). New and unrecognised are not the same thing as dangerous, but Windows cannot tell the difference from the file alone, so it warns about both. The exact screens you will see, word for word, are on the security warning page.

Can they see my screen when nobody is connected?

No. FlashDesk only captures and sends your screen while a session is live — after someone has connected and you have pressed Accept. There is no background service and nothing runs after you close the program.

Can someone get in without me agreeing?

No. The first time someone connects, FlashDesk shows a dialog with the caller's number and an Accept / Reject choice, and it defaults to Reject if left alone. If a connection drops and the same caller reconnects within 90 seconds, that resumes without asking again — a different caller is always asked. There is no remote way to answer that dialog for you: FlashDesk's own remote-control input is blocked from reaching it while it is open.

How do I stop it?

Click Disconnect on the strip that stays on your screen the whole time someone is connected, or just close the FlashDesk window. Either one ends the session immediately.

Does it install anything?

No. It is one file you double-click. Nothing is added to Windows, no admin password is asked for to run it, and closing the window removes it from memory completely — the next time you want to use it, you open the same file again.

Is it free?

Yes.

What do I do if someone phones claiming to be from FlashDesk?

Hang up. FlashDesk does not make outbound calls to anyone, ever. There is no support line that calls you, no "security team" that reaches out first. If a call like that happens, it is not us — see the line at the bottom of every page on this site.
